Claudeが積む。
Tsugumi の作られ方。

研究の試行錯誤を「見て、確かめて、手を入れられる形」で残す macOS ワークベンチ Tsugumi。それをひとりの人と Claude がどう作ったのかを、開発セッションとGit履歴からたどれるようにした記録です。何を頼み、どこで止め、何を確かめたか。

▶ 記録をたどる
▤ コードの行数の推移main の各コミット後 · 生成物・文法・文書は除く

数字はすべて の範囲で数えています（セッション数だけは全期間）。コミットは main に入ったもの（統合コミットを除く）、PR・リリースは GitHub、人の指示・Claude の報告・セッションは Claude Code の全 Tsugumi セッションから数えました。「Claudeの報告」は応答の区切りになった発言の数で、動作を独立に検証したものではありません。

01 · Output

作ったもの

計算やデータ処理を Card のグラフとして組み、AI と実装し、Nix で固定した環境で実行する。入力・コード・出力・実行履歴が残るので、気になった箇所に戻ってやり直せる。

02 · Process

速く作るために、
Claude への渡し方を三度変えた

骨格を立てる、大きく直す、公開後に細かく磨く。開発の段階ごとに、Claude へ仕事を渡す単位を意図して切り替えました。単位はコミット、指摘をまとめた md 文書、PR です。本人の説明に、Git 履歴と記録から数えた規模を添えています。Claude への指示は、短く言い切る命令形で書いています。

▶ 開発のパイプライン数字は記録から自動で集計
境目：最初のレビュー文書のコミット（11/2 16:56）と、最初の PR 統合（#17、11/4 13:21）第2段階にも会話での指示は続き、第3段階にも文書での指示がある
▥ 1日ごとのコミットと PR 統合JST · 日付の横はその日に含まれる段階
コミット（main の履歴。PR 内のコミットを含み、統合コミットは除く）PR の統合（Git 履歴と GitHub での確認）

人が持ったもの

  • 仕様書の原案と設計の考え（Nix で環境を固定する、core を分ける）
  • 触って見つけた指摘。箇条書きで md に書く
  • やるか・やらないか、統合してよいかの判断
  • 研究者やコミュニティへの共有と聞き取り

Claude に任せたもの

  • 実装とテスト。core・SDK・Mac アプリ・Web 版・デモ
  • 指摘の清書と、独立に進められる作業単位への分割
  • 自分のコードへの公開前レビューと、その修正
  • PR の作成・CI の修正・統合・リリース、ドキュメントの整理、この記録の表示
03 · Run timeline

Tsugumi が Card の実行を時間軸で見せるように、開発そのものを並べました。橙の縦線は人の指示、紫は PR の統合、青い柱は同時に動いていた Claude のセッション数、緑は Claude の報告の量。後半は作業ツリーごとにセッションを分けて並行に進めたので、全セッションから時刻と件数だけを数えています。Key Event は下の Workflow の各 Card で、押すとその Card へ移ります。

06 · Playbook

ひとりと Claude で作るための型

記録に取り込んだ人の指示（）を見出しの語で四つに分けると、「作って」と頼んだ回数よりも、決める・問うほうが多い。記録から見えた進め方を六つにまとめます。

内訳は記録担当が付けた見出しの語（方針・確認・依頼・push など）による機械的な分類で、厳密な分類ではありません。

07 · About

この記録について

開発中の会話・コミット・レビューは別の場所に残していますが、ここに載せたのはその要約と、選んだ指示の引用です。個人的な内容や認証情報が混じっていないことを全件では保証できないため、Claude の報告の本文やレビュー文書の原文は公開していません。

載せたもの
各段階の要約と教訓（Claude が記録から書いたもの）、人の指示を要約した見出し、GitHub で公開されているコミット・PR・リリースの事実、開発の段階ごとに選んだ本人の指示の引用（内容のみ）、「密着」と一部の Card に付けたセッションでのやりとりの要約、デモ映像に使われたインタビューの発言、件数と時刻。
載せていないもの
Claude の報告の本文、人名・ファイルの場所・録音のファイル名、レビュー文書の原文、作業途中の進行メモ、個人の予定やアカウントの情報、他の AI との私的な相談。
読み方
「Claudeの報告」は発言の記録で、動作を独立に検証したものではありません。コードと履歴は gen740/Tsugumi で確かめられます。
